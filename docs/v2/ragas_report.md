# v2 M2: 自写 RAG 评估

## 为什么自写（不用 RAGAS）

RAGAS 是"行业标准" —— 但**我项目里踩了 3 次坑**：
1. `ragas 0.3.2` —— `import` 报 `vertexai` 找不到
2. `ragas 0.1.21` —— 强依赖 `langchain-core<0.3` —— 把 langchain 降级
3. `ragas 0.1.20` —— 降级 `numpy` —— Windows 编译失败

**我选"自写"** —— 不是"RAGAS 不好" —— 是"我项目的约束 + 工程可控"。
